# TTT Elementor Snippets

**Production Elementor widget code, published as raw snippets.**
6,200+ lines of PHP, CSS and JS across ten widgets — exactly as we ship them.

---

## What's inside

| Widget | Lines | What it does |
|---|---:|---|
| `ttt-category-tabs` | ~1,100 | Category tabbed browsing |
| `ttt-image-plus` | ~890 | Enhanced image element |
| `ttt-partners` | ~870 | Partner / brand logo grid |
| `ttt-post-navigation` | ~720 | Post previous / next navigation |
| `ttt-grid-card` | ~620 | Responsive card grid |
| `ttt-smooth-scroll` | ~620 | Smooth scroll behaviour |
| `ttt-scf-accordion-pro` | ~440 | SCF accordion (Pro variant) |
| `ttt-menu-list` | ~410 | Menu list element |
| `ttt-scf-accordion` | ~290 | SCF accordion |
| `ttt-floating-container` | ~210 | Floating container show / hide logic |

Each directory holds that widget's `.php` / `.css` / `.js` segments. Several components
include their original development notes under `docs/` — dev guides and iteration summaries,
kept as written during the work.

## What this repository is

**Published to show how we build — not a plugin distribution.**

- These are **snippets**, not installable plugins. There is no main plugin file, no activation flow.
- **No installation guide. No support. No portability guarantee.**
- The code assumes an Elementor-based WordPress stack and our own internal conventions.

If you're evaluating our engineering, read the code.
If you need something installable and supported, this is not it.
